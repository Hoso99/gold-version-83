# Gold Version 8.3

Public Streamlit research application for a calibrated, one-hour gold forecasting ensemble.

## Deployment

Deploy `app_v83.py` with Streamlit Community Cloud. Add the following secret in the Streamlit app settings; never commit it to GitHub:

```toml
TWELVE_DATA_API_KEY = "your-key-here"
```

This software is for research and paper testing only. It does not guarantee accuracy or profit.
